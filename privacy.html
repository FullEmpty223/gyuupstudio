개인정보처리방침

시행일: 2026-11-25

수집하는 정보

GyuupStudio는 사용자가 Google 계정으로 로그인하면 YouTube Data API와 YouTube Analytics API로 해당 계정 채널의 읽기 전용 정보(채널 정보, 영상 목록, 조회수 등 통계)를 가져옵니다. 요청 권한은 youtube.readonly, yt-analytics.readonly 뿐이며, 영상을 올리거나 수정·삭제하지 않습니다.

저장과 공유

로그인 토큰은 사용자 기기의 Keychain에만 저장됩니다. 가져온 데이터는 기기 화면에 보여주는 데만 쓰며, 개발자 서버를 포함한 어떤 제3자에게도 전송·판매·공유하지 않습니다.

Google API 서비스 사용자 데이터 정책 준수

Google API에서 받은 정보의 사용과 전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다. YouTube API 사용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

권한 철회와 삭제

앱에서 로그아웃하면 기기의 토큰이 삭제됩니다. Google 계정 권한 설정에서 언제든 접근 권한을 철회할 수 있습니다.

Privacy Policy (English)

GyuupStudio reads, with the user's consent, read-only data about the signed-in user's own YouTube channels via the YouTube Data API and YouTube Analytics API (scopes: youtube.readonly, yt-analytics.readonly). Tokens are stored only in the device Keychain. Data is displayed on the device only and is never transferred, sold or shared with any third party, including the developer's servers. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The YouTube Terms of Service and Google Privacy Policy apply. Signing out deletes the tokens; access can be revoked at Google Account permissions. Contact: GitHub issues.
